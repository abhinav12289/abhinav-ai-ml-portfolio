### 1. Python Characteristics
- **No variable declaration** needed — just assign and go
- **Dynamically typed** — Python figures out the type automatically
- **Indentation** defines code blocks (instead of `{}`)
- Emphasis on **readability** — clean, human-like syntax

---

### 2. Variables & Assignment
```python
spam_amount = 0             # creates variable, assigns value
spam_amount = spam_amount + 4  # right side evaluated FIRST, then stored
```
- `=` is the **assignment operator** (not "equals"!)
- Right side is always evaluated before storing

> 💡 `x = x + 1` works because Python reads the old x first, adds 1, then stores the result back. This is how incrementing works.

---

### 3. print() & Function Calls
```python
print(spam_amount)    # outputs to screen
```
- **Built-in functions** come ready-to-use in Python
- Syntax: `function_name(arguments)`

---

### 4. Comments
```python
# This is a comment — ignored by Python
x = 5   # inline comment
```
> 💡 Write comments that explain **why**, not just what. Future-you will thank present-you.

---

### 5. Conditionals (if / elif / else)
```python
if spam_amount > 0:
    print("Spam!")
elif spam_amount == 0:
    print("No spam")
else:
    print("Negative spam?")
```
- `:` starts the block
- **4-space indentation** defines the block
- Python uses indentation **instead of {}** — wrong indent = crash

---

### 6. Strings
```python
"Hello World"     # double quotes
'It's fine'      # single quotes
"Spam " * 4       # → "Spam Spam Spam Spam "  (repetition)
"Hello" + " World" # → "Hello World"          (concatenation)
```
- `*` repeats, `+` joins — **operator overloading** (same symbol, different type = different behaviour)
- Use double quotes when string contains `'`

### 8. Arithmetic Operators

| Op | Meaning | Example | Result |
|----|---------|---------|--------|
| `+` | Addition | `3+2` | `5` |
| `-` | Subtraction | `5-2` | `3` |
| `*` | Multiplication | `4*3` | `12` |
| `/` | True Division | `5/2` | `2.5` |
| `//` | Floor Division | `5//2` | `2` |
| `%` | Modulus | `7%3` | `1` |
| `**` | Exponentiation | `2**3` | `8` |

```python
5 / 2    # 2.5  ← always float
5 // 2   # 2    ← truncates decimal (rounds DOWN)
-7 // 2  # -4   ← rounds toward -infinity, not zero!
7 % 3    # 1    ← remainder
```

> 💡 `%` (modulus) is more useful than it looks: `x % 2 == 0` checks if x is even. You'll use this constantly.

---

### 9. Order of Operations (PEMDAS)
```
Parentheses → Exponents → Multiply/Divide → Add/Subtract
```
```python
-3 + 4 * 2           # 5  (multiply first)
(-3 + 4) * 2         # 2  (parentheses first)
(height_cm) / 100    # ✅ correct grouping
```
> 💡 When in doubt, add parentheses. They cost nothing and prevent bugs.

### 11. Type Conversion
```python
float(10)        # 10.0
int(3.99)        # 3      ← TRUNCATES, does NOT round
int('807') + 1   # 808
str(42)          # "42"
```
> ⚠️ `int()` truncates — `int(3.9)` = `3`, not `4`. Use `round()` first if you need rounding.
> ⚠️ `int("3.14")` crashes — can't go float-string → int directly. Do `int(float("3.14"))`.

---

### 12. help() Function
```python
help(round)      # ✅ shows docs for the function
help(round())    # ❌ shows docs for the result (a number) — WRONG!
```

---

### 13. Defining Functions
```python
def least_difference(a, b, c):
    """Returns smallest difference between any two of a, b, c."""
    return min(abs(a-b), abs(b-c), abs(a-c))
```
- `def` keyword + name + parameters + `:`
- `return` → sends value back AND ends the function
- Docstring (`"""..."""`) → shown by `help()`
- No `return` → function gives back `None`

> 💡 `print()` and `return` are completely different. print() shows something on screen (side effect). return sends a value back to whoever called the function. Confusing them = very common bug.

---

### 14. Default Arguments & Functions as Arguments
```python
def greet(name="User"):
    print("Hello", name)

greet()            # Hello User
greet("Abhinav")   # Hello Abhinav

# Functions can be passed as arguments!
max(100, 51, 14, key=lambda x: x % 5)  # 14
# (returns value with highest x % 5)
```

> 💡 The `key=` argument is used everywhere in Python — sorting, filtering, finding max/min with custom logic. In ML, you'll use it constantly with pandas. Master it now.

### 15. Booleans ✅
```python
# Only two values — must be CAPITALIZED
True   False

type(True)   # bool

# Comparison operators (always return bool)
3 == 3   # True     3 != 4  # True
2 < 5    # True     5 > 3   # True
3 <= 3   # True     4 >= 5  # False

# Boolean operators
True and False   # False  (both must be True)
True or False    # True   (at least one must be True)
not True         # False  (flips the value)

# In conditionals
if age >= 18 and has_id:
    print("Entry allowed")

# bool() conversion — Truthy and Falsy
bool(1)      # True    bool(0)    # False
bool("hi")   # True    bool("")   # False
bool(None)   # False
```

**Common mistakes:**
- `=` is assignment → `==` is comparison — NEVER mix them
- `true` / `false` → WRONG. Must be `True` / `False`

> 💡 Truthy/Falsy tip: instead of `if len(my_list) > 0:` just write `if my_list:` — empty list is Falsy, non-empty is Truthy. This is more "Pythonic".
